\chapter{Structural Profile Labeling Prompt}
\label{app:dna-prompt}

The prompt below was used by both GPT-5-mini and Gemini~2.5~Flash to label each URL's structural characteristics (Section~\ref{sec:content-dna}). The pipeline feeds in the URL, page title, meta description, and extracted text; the model returns a JSON object with the fields shown.

\begin{lstlisting}
You are labeling a web page for a research dataset.
Use ONLY the provided inputs (URL, title, snippet/meta,
extracted text). Do NOT browse the web.

Return ONLY valid JSON. No markdown. No commentary.
No trailing commas. If info is missing, use empty string,
0, or [] -- do NOT guess.

## Enums
type (choose exactly one):
- listicle
- marketplace_directory
- app_store_listing
- product_page
- category_page
- review_article
- comparison_article
- documentation
- forum_ugc
- news_article
- editorial_article
- reference
- other

content_format (choose exactly one):
- best_of_list
- alternatives_list
- comparison_matrix
- single_review
- howto_guide
- faq
- landing_page
- directory_listing
- announcement_news
- other

tone (choose exactly one):
- neutral_informational
- promotional
- salesy
- academic_technical
- opinionated
- other

primary_intent (choose exactly one):
- informational
- commercial
- transactional
- navigational

## Scales
promotional_intensity_score: integer 0-5
expertise_signal_score: integer 0-5
spamminess_score: integer 0-5
freshness_cue_strength: integer 0-5
heading_density: integer 0-5
readability_score: integer 0-5
has_tables: 1 if the page contains data grids,
  comparison tables, or structured rows/columns.
has_numbered_lists: 1 if the page uses explicit
  "1., 2., 3." or "First, Second..." numbering.
has_bullet_points: 1 if the page uses clear
  bulleted lists.
has_pros_cons: 1 if the page clearly contains a
  Pros/Cons section or equivalent.
has_clear_authorship: 1 if explicit author/editor
  attribution exists.
has_sources_or_citations: 1 if the page text
  indicates sources/references/citations.
listicle_has_ranked_order: 1 if the listicle
  uses rankings.
is_current_year_2026: 1 if the page explicitly
  mentions "2026" in the title or text.

}

\end{lstlisting}
